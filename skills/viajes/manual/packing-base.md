# Lista de empaque base

> Base fija para cualquier viaje. El asesor la copia a `viajes/<viaje>/packing.md` y le suma los extras del destino.
> Ajustes personales del usuario ("siempre se me olvida X", "esto nunca lo uso") van en `config.md` → Lista de empaque, NO aquí: este archivo es la base genérica del paquete.

## Documentos y plata
- [ ] Pasaporte (vigencia > 6 meses al regresar) + documento de identidad
- [ ] Visas, ETA o eVisa impresas o en el celular, si aplican
- [ ] Certificado de fiebre amarilla, si el destino lo pide
- [ ] Seguro de viaje (póliza en PDF)
- [ ] Reservas: vuelos, hoteles y entradas (offline en el celular)
- [ ] 2 tarjetas en bancos distintos + algo de efectivo en la moneda del destino o en USD/EUR
- [ ] Licencia de conducción (+ permiso internacional si va a alquilar carro y el país lo pide)

## Tecnología
- [ ] Celular + cargador + cable de repuesto
- [ ] Power bank
- [ ] Adaptador de enchufe del destino
- [ ] eSIM o plan de datos activado antes de salir
- [ ] Audífonos
- [ ] Mapas offline del destino (Google Maps)

## Ropa (ajustar por días y clima)
- [ ] Ropa interior y medias: días + 1
- [ ] Camisetas / camisas
- [ ] Pantalones / bermudas
- [ ] Una muda "elegante" para una cena buena
- [ ] Chaqueta liviana
- [ ] Zapatos cómodos para caminar + uno más
- [ ] Pijama

## Aseo y salud
- [ ] Cepillo, crema dental, desodorante y cosas de afeitar (líquidos ≤100 ml en el equipaje de mano)
- [ ] Protector solar
- [ ] Botiquín: analgésico, antidiarreico, antialérgico, curitas y medicamentos personales con fórmula

## Equipaje de mano
- [ ] Muda de ropa por si se pierde la maleta
- [ ] Almohada de viaje y antifaz (vuelos largos)
- [ ] Botella de agua vacía
- [ ] Lapicero (formularios de migración)
